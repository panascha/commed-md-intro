# 04 การสรุปข้อมูล การมีส่วนร่วม และ Public Forum — Keyword ก่อนสอบ

> Source: topic md 04 + MCQ COMMED2_40/44/46/50/xx (24 ข้อ cross-check ตรงหัวข้อนี้)
> 🔥 = จุดตัดสินคะแนน/สอบซ้ำหลายชุด · ⚠️ = ตัวลวงที่ MCQ ออกจริง

---

## เวทีสาธารณะ (Public Forum) — ระดับ & วัตถุประสงค์

* 🎯 **โจทย์: วัตถุประสงค์หลักของเวทีสาธารณะคืออะไร**
  * **เอาไว้เขียนตอบ:**
    * 🔥 **เปิดโอกาสให้ชุมชนแสดงความคิดเห็นอย่างเท่าเทียม + ร่วมกันแก้ไขปัญหา** (Community Participation)
    * ประโยชน์: ชุมชนจัดการทรัพยากรที่มีอยู่ได้เหมาะสม, ชุมชนมีส่วนร่วมเลือกปัญหา
  * **เนื้อหาที่เกี่ยวข้อง:**
    * ⚠️ **"จำกัดสิทธิพูดเฉพาะผู้นำชุมชน"** = ผิดหลักการเวทีสาธารณะเสมอ (ต้องเท่าเทียมทุกภาคส่วน)
    * ⚠️ **"คืนข้อมูลด้วยภาษาทางการ/ศัพท์เทคนิค"** = ข้อที่**ไม่เหมาะสม** — ต้องใช้ภาษาเข้าใจง่าย เป็นกันเอง

* 🎯 **โจทย์: แยกระดับเวทีประชาคม (คุ้ม vs หมู่บ้าน/เขต)**
  * **เอาไว้เขียนตอบ:**
    * 🔥 **ระดับคุ้ม (หย่อมบ้าน)** = หน่วยย่อยที่สุด บรรยากาศเป็นกันเอง (เช่น สันทนาการรอบกองไฟ) → **นำเสนอข้อมูลคืนสู่ชุมชน + จัดลำดับความสำคัญปัญหาเบื้องต้น**
    * **ระดับหมู่บ้าน/เขต** = ตัวแทนจากทุกคุ้มมาสะท้อนภาพรวม กึ่งทางการ, Bottom-up → **ระดมความคิด เสนอแนวทางแก้ไขปัญหาที่จัดลำดับมาแล้ว** → ร่างแผนชุมชน

## จัดลำดับความสำคัญของปัญหา (Priority Setting) — 4 เกณฑ์

* 🎯 **โจทย์: 4 เกณฑ์จัดลำดับความสำคัญของปัญหาคืออะไร แยกแต่ละตัว**
  * **เอาไว้เขียนตอบ:**
    * 🔥 **Size of problem (ขนาดของปัญหา)** = ผลกระทบ/ร้อยละของคนที่เป็น — คะแนน 1-4 ตามช่วงร้อยละ (0-25%→1, 26-50%→2, 51-75%→3, 76-100%→4)
    * 🔥 **Severity (ความรุนแรง)** = **5 D's: Death, Disease, Disability, Discomfort, Dissatisfaction**
    * 🔥 **Feasibility (ความยากง่ายในการแก้ไข)** = **4 M's: Man, Money, Material, Management** + ด้านวิชาการ/เวลา/กฎหมาย/**ศีลธรรมจรรยา**
    * **Community concern (ความตระหนักของชุมชน)** = นโยบาย/กฎหมาย/ความคิดเห็น/ความสนใจผู้นำ/ภาพลักษณ์ชุมชน
  * **เนื้อหาที่เกี่ยวข้อง:**
    * ⚠️ "วิธีแก้ไขไม่ขัดศีลธรรมจรรยา" = เกณฑ์ **Feasibility** (ไม่ใช่ Size หรือ Concern — ตัวลวงที่ออกจริง)
    * ⚠️ คะแนน **R (Feasibility/Resource) สูง** = **แก้ไขได้ง่าย** (ไม่ใช่ยาก — ระวังตีความสลับ)

* 🎯 **โจทย์: เลือกปัญหาไหนทำโครงการ / คำนวณคะแนนรวม**
  * **เอาไว้เขียนตอบ:**
    * 🔥 **เลือกปัญหาที่ได้ผลรวมคะแนน (Total Score) สูงสุดเสมอ** — ตัวอย่างจริง: โรคไข้หวัด (Size=1 เพราะอัตราป่วย 10%≤25%; Severity=1 เพราะหายเองได้ไม่รุนแรง) vs **มะเร็งท่อน้ำดี คะแนนรวมสูงสุด (41 คะแนน) → เลือกอันดับแรก**
    * คะแนนรวม = ขนาด × ความรุนแรง × ความยากง่าย × ความตระหนัก (ตามตารางถ่วงน้ำหนักที่ให้ในโจทย์)
  * **เนื้อหาที่เกี่ยวข้อง:**
    * ⚠️ อย่าเลือกโรคจาก**ความชุกอย่างเดียว** — ต้องดูคะแนนรวมทั้ง 4 องค์ประกอบ

## การจัดกลุ่มปัญหา 3 กล่อง (สั้น/กลาง/ยาว)

* 🎯 **โจทย์: เกณฑ์แบ่ง 3 กล่อง + กล่องไหนนำเข้าเวทีก่อน**
  * **เอาไว้เขียนตอบ:**
    * 🔥 **เกณฑ์ = ระยะเวลาและทรัพยากรที่ต้องใช้แก้ไข** — กล่อง 1 (ยาว: แก้ยาก งบสูง) · กล่อง 2 (กลาง: ชุมชนทำเองได้แต่ใช้เวลา+ผู้เชี่ยวชาญ) · กล่อง 3 (สั้น: แก้ได้ทันทีใน 2-3 วันด้วยทรัพยากรที่มี)
    * 🔥 **กล่องที่ 2 และ 3 (ระยะกลาง+สั้น) นำเข้าเวทีระดับเขต/หมู่บ้านก่อนเป็นอันดับแรก** — เห็นผลเร็ว ไม่ทำให้ชาวบ้านท้อแท้

---

## การนำเสนอข้อมูลต่อชุมชน

* 🎯 **โจทย์: เลือกรูปแบบกราฟ/แผนภูมิให้เหมาะกับข้อมูล**
  * **เอาไว้เขียนตอบ:**
    * 🔥 **ข้อมูลอนุกรมเวลา/แนวโน้มหลายปี (Trend)** → **กราฟเส้น (Line graph)**
    * 🔥 **เปรียบเทียบหลายโรค/หลายกลุ่มในช่วงเวลาเดียวกัน** → **แผนภูมิแท่ง (Bar chart)**

## ตารางสรุปจำเร็วหน้าห้องสอบ (Cheat Sheet)

| ประเด็น | คำตอบหลัก |
| :--- | :--- |
| **เวทีระดับคุ้ม** | คืนข้อมูล + จัดลำดับปัญหาเบื้องต้น |
| **เวทีระดับหมู่บ้าน/เขต** | เสนอแนวทางแก้ไข → ร่างแผนชุมชน |
| **Severity** | 5 D's |
| **Feasibility** | 4 M's + กฎหมาย/ศีลธรรม |
| **เลือกปัญหาทำโครงการ** | Total score สูงสุด |
| **กล่องปัญหาเข้าเวทีก่อน** | สั้น+กลาง (2,3) |
| **Trend หลายปี** | กราฟเส้น |
| **เปรียบเทียบหลายโรค** | แผนภูมิแท่ง |
