## INHOMESSS — จัดข้อมูล/ประเด็นให้ตรงหมวด

* **หลักการและกลไก:** INHOMESSS = **I**mmobility, **N**utrition, **H**ousing, **O**ther people, **M**edication, **E**xamination, **S**afety, **S**piritual, **S**tory (S ตัวสุดท้ายปรับจาก Service → Story)

* 🎯 **โจทย์: ข้อมูล/สถานการณ์นี้จัดอยู่หมวดไหนของ INHOMESSS**
  * **เอาไว้เขียนตอบ:**
    * 🔥 **Housing** = ตัวบ้าน+สิ่งแวดล้อมรอบบ้าน (โครงสร้าง, แอ่งน้ำขัง, คอกสัตว์ใกล้บ้าน, ของประดับตกแต่ง/โล่รางวัลในบ้าน) — **ไม่ใช่ประเมินว่าดี/ไม่ดี** แค่บรรยายลักษณะ
    * 🔥 **Safety** = ความปลอดภัยทางกายภาพเฉพาะจุด (เตียงไม่มีราวกั้น เสี่ยงตกเตียง, พื้นลื่น, ปลั๊กไฟ)
    * 🔥 **Examination** = ตรวจร่างกาย/สังเกตอาการทางคลินิกโดยตรง (petechiae, ascites, จุดเลือดออก) **รวมถึง self-assessment สุขภาพตนเอง**
    * **Other people** = ความสัมพันธ์กับบุคคลภายนอก/สังคม — **ใช้ Eco-map ประเมินหมวดนี้**
    * **Medication** = พฤติกรรม/อุปสรรคการใช้ยา (เช่น สายตาไม่ดีอ่านฉลากยาไม่ได้ → ลูกจัดยาให้)
    * **Story** = เหตุการณ์สำคัญ/ประวัติความเป็นมาของครอบครัว
  * **เนื้อหาที่เกี่ยวข้อง:**
    * ⚠️ ระวังแยก Housing (โครงสร้าง/สิ่งแวดล้อม) vs Safety (อันตรายเฉพาะจุด) vs Other people (คนภายนอก) — MCQ ชอบเอาโจทย์คล้ายกันมาให้เลือกผิดหมวด

## Eco-map vs Genogram

* 🎯 **โจทย์: Eco-map ใช้ทำอะไร**
  * **เอาไว้เขียนตอบ:**
    * 🔥 **Eco-map = เครื่องมือของหมวด "Other people"** — แสดงความสัมพันธ์สมาชิกครอบครัวกับบุคคล/ระบบภายนอก (social support)

* 🎯 **โจทย์: สัญลักษณ์ผังเครือญาติครอบครัว (Family Genogram) แปลว่าอะไร**
  * **เอาไว้เขียนตอบ:**
    * 🔥 สี่เหลี่ยม = ชาย · วงกลม = หญิง
    * 🔥 เส้นวงรีล้อมรอบคู่ = **แต่งงานกันและอยู่ด้วยกัน**
    * 🔥 สี่เหลี่ยม+วงกลมอยู่ **ในวงรีเดียวกัน เชื่อมด้วยเส้นคู่ขนาน** = **สนิทกันและอยู่ด้วยกัน** (คนละความหมายกับ "แต่งงานกัน" ด้านบน — ระวังสับสน 2 สัญลักษณ์นี้)
    * 🔥 เส้นลูกศรหยัก (zigzag) จากชาย→หญิง = **ความรุนแรง/ถูกกระทำทารุณกรรม** (ฝ่ายหญิงถูกกระทำโดยฝ่ายชาย)
    * ภาพสัญลักษณ์จริงจากข้อสอบ (ครอปจาก PDF ต้นฉบับ): `MCQ/img/genogram_46mcq1_q26.png`, `genogram_45mcq1_q7.png`, `genogram_44mcq1_q8.png`, `genogram_44mcq1_q9.png`

## เลือกครอบครัวศึกษา (เกณฑ์คัดเลือก)

* 🎯 **โจทย์: ควรเลือกครอบครัวแบบไหนศึกษา**
  * **เอาไว้เขียนตอบ:**
    * 🔥 **ครอบครัวทุกขภาวะที่ปลอดภัยพอให้เรียนรู้** — มีผู้ดูแล (caregiver) ให้ข้อมูลได้ดี เช่น **ผู้ป่วย Stroke/นอนติดเตียง มีลูกสาว/หลานสาวดูแล** หรือผู้ป่วยติดเตียงที่มีภาระค่าใช้จ่ายสูง (Vulnerable family)
    * **ครอบครัวสุขภาวะตัวอย่าง** — เช่น ครอบครัวเกษตรกรที่ใช้**หลักเศรษฐกิจพอเพียง** (ทำเกษตรประณีต ขายผลผลิตในชุมชน = พอประมาณ+มีเหตุผล+มีภูมิคุ้มกัน)
  * **เนื้อหาที่เกี่ยวข้อง:**
    * ⚠️ **หลีกเลี่ยง** ครอบครัวที่มีความเสี่ยงด้านความปลอดภัย (เช่น วัณโรคระยะแพร่เชื้อ), สื่อสารไม่ได้รุนแรง (สมองเสื่อมอยู่คนเดียว), หรือหวาดกลัวคนแปลกหน้า (ผู้ป่วยจิตเวช)

* 🎯 **โจทย์: เทคนิคเก็บข้อมูลครอบครัว**
  * **เอาไว้เขียนตอบ:**
    * 🔥 **พูดภาษาถิ่นไม่ได้ → ใช้ภาษาไทยกลางแทน** (วิธีที่เหมาะสมที่สุด)
  * **เนื้อหาที่เกี่ยวข้อง:**
    * ⚠️ ตัวลวง: เก็บข้อมูลดึกเกิน (22.00 น.), สัมภาษณ์นานเกิน (3 ชม.ครั้งเดียว), ให้คำแนะนำทางการแพทย์ทันทีโดยยังไม่ปรึกษาอาจารย์ = ผิดหลักทั้งหมด

## ทฤษฎีครอบครัว & บทบาทหน้าที่

* 🎯 **โจทย์: หน้าที่/บทบาทของครอบครัวที่ส่งเสริมสุขภาพโดยตรงคืออะไร**
  * **เอาไว้เขียนตอบ:**
    * 🔥 **หน้าที่ที่ส่งเสริมสุขภาพโดยตรง = การดูแลสุขภาพและจัดหาปัจจัยพื้นฐาน** (ไม่ใช่การจัดการเศรษฐกิจ/อบรมสั่งสอน/ให้ความรัก ซึ่งส่งเสริมทางอ้อม)
    * บทบาทมารดา (primary caregiver) ด้านบ้าน/อาหาร/พาไปรับบริการสุขภาพ = ปัจจัยพื้นฐานที่ดีต่อสุขภาพสมาชิก

* 🎯 **โจทย์: อะไรสะท้อนโครงสร้างอำนาจ (Power Structure) ในครอบครัวชัดที่สุด**
  * **เอาไว้เขียนตอบ:**
    * 🔥 **การตัดสินใจของคนในครอบครัว (Family Decision Making)** สะท้อนบทบาท/อำนาจ/อิทธิพลชัดที่สุด

* 🎯 **โจทย์: วัตถุประสงค์ของการศึกษาครอบครัว (Family Study) คืออะไร**
  * **เอาไว้เขียนตอบ:**
    * เข้าใจวิถีชีวิต ระบบสุขภาพ โครงสร้างครอบครัวผ่าน INHOMESSS
  * **เนื้อหาที่เกี่ยวข้อง:**
    * ⚠️ **"ปรับตัวเข้าหาสภาพแวดล้อมชุมชน"** = เป้าหมายระดับ**ชุมชนภาพรวม** ไม่ใช่วัตถุประสงค์เฉพาะของการศึกษาครอบครัวรายบ้าน — ตัวลวงที่ออกซ้ำ
    * ⚠️ **"ให้นักศึกษาได้คุยกับครอบครัวอื่นที่ไม่ใช่ครอบครัวตัวเอง"** = **ไม่ใช่**วัตถุประสงค์ของการศึกษาครอบครัว (Med45 ข้อ 1) — วัตถุประสงค์จริงคือศึกษาวิถีชีวิต/ระบบสุขภาพ/ฝึก INHOMESSS ของครอบครัวที่ไปเยี่ยม

## ตารางสรุปจำเร็วหน้าห้องสอบ (Cheat Sheet)

| หมวด INHOMESSS | เนื้อหา |
| :--- | :--- |
| **I**mmobility | ADL, กิจวัตรประจำวัน |
| **N**utrition | อาหาร/พฤติกรรมกิน |
| **H**ousing | ตัวบ้าน+สิ่งแวดล้อมรอบบ้าน (ไม่ตัดสินดี/ไม่ดี) |
| **O**ther people | คนภายนอก/สังคม → ใช้ Eco-map |
| **M**edication | พฤติกรรม/อุปสรรคใช้ยา |
| **E**xamination | ตรวจร่างกาย+self-assessment |
| **S**afety | อันตรายเฉพาะจุดในบ้าน |
| **S**piritual | ความเชื่อ/คุณค่าทางใจ |
| **S**tory | ประวัติ/เหตุการณ์สำคัญครอบครัว |
